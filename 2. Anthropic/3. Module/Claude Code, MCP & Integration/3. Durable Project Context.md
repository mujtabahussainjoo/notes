### Summary: Managing Durable Project Context with CLAUDE.md, Rules Files, Hooks, and Subagents

#### Introduction
This summary explains how to effectively manage project context when using Claude Code. By utilizing **CLAUDE.md**, rules files, hooks, and subagents, you can ensure that the important rules and behaviors you set in your coding sessions remain consistent and effective.

### Key Components

1. **CLAUDE.md: The Project File**
   - **What It Is:** Every time you start Claude Code, it looks for a file named **CLAUDE.md** in your project folder. This file contains important rules and instructions for your project.
   - **How It Works:** The contents of this file are automatically added to your session, meaning you don’t have to repeat the same instructions every time you start working.

   **Example:**
   - If **CLAUDE.md** contains the rule, "Always use version 3.0 of the API," this rule will apply automatically every time you work on that project.

2. **Managing the Size of CLAUDE.md:**
   - **Why Size Matters:** If **CLAUDE.md** gets too large (more than a few hundred lines), it can make it harder for the agent to follow critical rules because everything gets diluted.
   - **What to Do:** Keep it concise. Only include essential rules that directly impact how the agent works. Move less important instructions to **Skills** that can be loaded only when needed.

3. **Rules Instruction Files:**
   - **Purpose:** For rules that apply only to specific parts of your project, use **rules instruction files**. These are stored in a folder called **.claude/rules/**.
   - **Scoping Rules:** You can specify which files these rules apply to, ensuring that they are loaded only when relevant.

   **Example:**
   - If you have a rule like, "All SQL files in the database module must include a transaction boundary," you can store it in a rules file that only loads when working with SQL files.

4. **Hooks: Automating Actions**
   - **What Are Hooks?** Hooks let you run scripts automatically at specific points in the workflow. This ensures that important tasks occur every time without manual input.
   
   **Types of Hooks:**
   - **PreToolUse:** Runs before any tool is used. You can block actions here if they are not allowed.
   - **PostToolUse:** Runs after a tool is used, perfect for tasks like formatting code or logging changes.
   - **UserPromptSubmit:** Runs when you submit a prompt, allowing you to add context before anything is processed.

   **Example:**
   - Set up a hook to format your code using Prettier every time you save a file, ensuring consistent style across your project.

5. **Subagents: Isolated Work**
   - **What Are Subagents?** Subagents are specialized helpers that can carry out tasks without influencing your main project context. They start fresh each time and return only their results.
   - **Why Use Subagents?** They are useful for tasks that need to be executed separately from existing context or rules.

   **Example:**
   - If you want to explore a new feature in the code independently, you can delegate that task to a subagent for efficiency.

### Managing Project Context

1. **What Goes Where:**
   - Use **CLAUDE.md** for universal rules that apply to the entire project.
   - Use **rules files** for specific instructions that only apply to certain parts of the code.
   - Use **hooks** for automated tasks that enforce rules.
   - Use **subagents** for tasks that should run in isolation.

2. **Example of a Settings File:**
   Here’s how you might set up a hook to prevent access to sensitive files:

   ```json
   {
     "hooks": {
       "PreToolUse": [
         {
           "matcher": "Read",
           "hooks": [{ "type": "command", "command": "exit 2" }]
         }
       ]
     }
   }
   ```

### Conclusion
By effectively using CLAUDE.md, rules files, hooks, and subagents, you can maintain a durable project context in Claude Code. This ensures that your coding environment stays consistent, safe, and efficient, reducing errors and improving your workflow. Always keep your rules organized and concise to maximize their effectiveness.
