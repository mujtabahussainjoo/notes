## Very simple text completion code

Once you have your key, you can call the completion (or chat) endpoint from code.

### Python example (completion style)

```python
import openai

openai.api_key = "YOUR_API_KEY"

prompt = "Write a short product description for a red running shoe."

response = openai.Completion.create(
    model="text-davinci-003",
    prompt=prompt,
    max_tokens=60,
    temperature=0.7,
)

print(response.choices[0].text.strip())
```

This sends a prompt and prints a short product description.

```python
import openai

openai.api_key = "YOUR_API_KEY"

messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain what an API is in one sentence."}
]

response = openai.ChatCompletion.create(
    model="gpt-3.5-turbo",
    messages=messages
)

print(response.choices[0].message["content"])
```
