1. **Reason:** think step by step about the goal.  
2. **Act:** call a tool or take an action.  
3. **Observe feedback:** see what happened.  
4. **Update reasoning:** change the plan if needed, then repeat.

```text
    ↑                ↓

             (feedback)
             ↓
        Stop or repeat
```

- **Reflex agents:** act instantly based on current input (fast but simple).  
- **Deliberative agents:** pause to plan before acting (better for complex tasks).  
- **Chain‑of‑Thought:** agent reasons in a clear, linear step‑by‑step fashion.  
- **Tree‑of‑Thought:** agent explores multiple possible solution paths before picking one.  
- **Multi‑agent roles:** agents act as planner, executor, verifier and collaborate toward a shared goal.  
- **Dynamic routing:** tasks go to the best agent based on role, availability, or performance.  
- **Feedback‑driven agents:** agents learn from tool failures, user corrections, and low confidence.  
- **Reflective patterns:** agents review and refine their own reasoning before giving a final answer.

## Main idea to remember

You can think of agentic AI design patterns as **ready‑made blueprints** for how an AI agent should behave:

```text
Trigger → Flow → Feedback → Role
       + ReAct loop for adaptive reasoning and action
```

Using these patterns, you don’t just create one clever agent; you learn **reusable ways** to build many clear, scalable, and intelligent agentic systems.
