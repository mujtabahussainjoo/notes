## 8. Tiny practical LangChain RAG example (single‑source)

Here’s a very simple, realistic pattern you can reuse for a basic doc‑based Q&A (e.g., your Magento project docs):

```python
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import HuggingFaceEmbeddings
from langchain_community.document_loaders import DirectoryLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.chains import RetrievalQA
from langchain_community.llms import HuggingFaceHub  # or any LLM you like

# 1. Load documents (e.g., Markdown docs about your project)
loader = DirectoryLoader("./docs", glob="**/*.md")
docs = loader.load()

# 2. Chunk documents
splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=100
)
chunks = splitter.split_documents(docs)

# 3. Create embeddings and vector store
emb_model = HuggingFaceEmbeddings(model_name="sentence-transformers/all-MiniLM-L6-v2")
vector_store = Chroma.from_documents(chunks, emb_model)

# 4. Build retriever and RAG chain
retriever = vector_store.as_retriever(search_type="mmr", search_kwargs={"k": 5})
llm = HuggingFaceHub(repo_id="google/flan-t5-xl")  # example; swap for your choice

qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    retriever=retriever,
    chain_type="stuff"  # simplest: stuff retrieved docs into prompt
)

# 5. Ask a question
answer = qa_chain.run("How do I configure payment methods in this project?")
print(answer)
```
