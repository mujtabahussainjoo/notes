## 1. Functions and functional patterns

A function is a reusable block of code that:

1. Receives input.
2. Performs a task.
3. Returns an output.

```python
def clean_text(text):
    return text.strip().lower()

result = clean_text("  Hello AI  ")
print(result)  # hello ai
```

Functions are useful in AI systems for small, separate tasks such as:

- Cleaning user input.
- Splitting documents.
- Creating prompts.
- Calling a model.
- Parsing model output.
- Validating results.

### Functional programming

Functional programming means building a larger task by connecting small functions together.

```python
def clean_text(text):
    return text.strip().lower()

def count_words(text):
    return len(text.split())

text = clean_text("  Python for AI  ")
result = count_words(text)

print(result)  # 3
```

Each function does one clear job.

### Pure functions

A pure function always gives the same output for the same input and does not secretly change anything outside itself.

```python
def add_tax(price):
    return price * 1.18
```

This is easy to test because its result depends only on `price`.

A function that changes a global variable, writes to a database, or calls an external API has a **side effect**. Side effects are sometimes necessary, but keeping them separate makes the code easier to understand and test. Python’s functional style emphasizes passing data through functions and reducing hidden state changes.

### Higher-order functions

Python functions can be treated like values. You can:

- Store them in variables.
- Pass them to other functions.
- Return them from functions.

```python
def apply_operation(value, operation):
    return operation(value)

def double(number):
    return number * 2

print(apply_operation(5, double))  # 10
```

This is useful when you want to choose different processing steps, such as different text-cleaning or scoring strategies.
