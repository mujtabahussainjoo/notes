## 3. Iterators, generators, and lazy evaluation

### Iterable

An iterable is something you can go through one item at a time.

Examples include:

- Lists.
- Tuples.
- Strings.
- Dictionaries.
- Files.

```python
for word in ["AI", "Python", "RAG"]:
    print(word)
```

### Iterator

An iterator gives you one item at a time and remembers where it stopped.

```python
numbers = iter([10, 20, 30])

print(next(numbers))  # 10
print(next(numbers))  # 20
print(next(numbers))  # 30
```

When there are no more items, the iterator ends.

Python iterators represent a stream of data and provide values one at a time instead of returning everything at once.

### Generator

A generator is an easy way to create an iterator. It uses `yield` instead of `return`.

```python
def generate_numbers():
    for number in range(3):
        yield number

for number in generate_numbers():
    print(number)
```

Output:

```text
0
1
2
```

A normal function calculates and returns a result. A generator pauses at `yield` and continues from that point the next time it is asked for a value.

### Lazy evaluation

Lazy evaluation means:

> Do the work only when the result is actually needed.

Example:

```python
def read_documents(documents):
    for document in documents:
        yield document.upper()
```

This does not process every document immediately. It processes one document at a time as the loop requests it.

### Why this matters in AI systems

Generators are useful when processing:

- Large files.
- Many documents.
- Long lists of search results.
- Streaming model responses.
- Large datasets.
- Document chunks for embeddings.

Without lazy processing, you might load thousands of documents into memory at once. With a generator, you can process them gradually.

```python
def chunks(text, size=100):
    for start in range(0, len(text), size):
        yield text[start:start + size]
```

This produces text chunks one at a time instead of creating all chunks immediately.

### Easy comparison

| Concept | Meaning |
|---|---|
| List | Stores all results immediately |
| Iterator | Gives one result at a time |
| Generator | An easy way to create an iterator |
| Lazy evaluation | Delays work until it is needed |
