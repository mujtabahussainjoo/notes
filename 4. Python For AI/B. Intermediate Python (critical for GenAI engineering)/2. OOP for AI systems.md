## 2. OOP for AI systems

Object-oriented programming, or OOP, groups:

- Data.
- The actions that use that data.

A **class** is like a blueprint. An **object** is something created from that blueprint.

```python
class Document:
    def __init__(self, text):
        self.text = text

    def word_count(self):
        return len(self.text.split())

document = Document("Python helps build AI systems")
print(document.word_count())  # 5
```

Here:

- `Document` is the class.
- `document` is the object.
- `text` is the object’s data.
- `word_count()` is its behavior.

### OOP example for an AI model

```python
class Summarizer:
    def __init__(self, model):
        self.model = model

    def summarize(self, text):
        prompt = f"Summarize this text:\n{text}"
        return self.model.generate(prompt)
```

The `Summarizer` object keeps the model and summarization behavior together.

OOP is useful when an AI system contains several related responsibilities, such as:

- A model client.
- A document loader.
- A retriever.
- A prompt builder.
- A tool manager.
- An agent.
- A conversation memory component.

### Why OOP helps

OOP can make large AI projects easier to manage because:

- Each class can have one main responsibility.
- Components can be replaced more easily.
- Configuration can be stored in one place.
- Behavior and related data stay together.
- Components can be tested separately.

For example, you can replace an OpenAI model client with a local model client while keeping the rest of the application unchanged, as long as both provide the same method.

Avoid creating one very large class that does everything. Smaller classes are usually easier to understand and maintain.
