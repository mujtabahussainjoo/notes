## 4. Context managers

A context manager safely manages a resource.

Common resources include:

- Files.
- Database connections.
- Network connections.
- Locks.
- Temporary resources.

The common pattern is:

```python
with resource:
    use_resource()
```

Example:

```python
with open("notes.txt", "r") as file:
    content = file.read()
```

Python automatically closes the file after the `with` block, even if an error occurs.

Without a context manager, you would need to close it manually:

```python
file = open("notes.txt", "r")

try:
    content = file.read()
finally:
    file.close()
```

The `with` version is shorter and safer.

### Custom context manager

```python
from contextlib import contextmanager

@contextmanager
def log_operation(name):
    print(f"Starting {name}")

    try:
        yield
    finally:
        print(f"Finished {name}")

with log_operation("summarization"):
    print("Calling the model")
```

The `finally` section runs even when an error occurs. Context managers define what should happen when entering and leaving a block of code.

### Use in AI systems

Context managers can help manage:

- Database sessions.
- API clients.
- Temporary files.
- Tracing spans.
- Timing measurements.
- Model resources.
- Locks around shared data.

Example:

```python
from time import perf_counter
from contextlib import contextmanager

@contextmanager
def measure_time(operation):
    start = perf_counter()

    try:
        yield
    finally:
        duration = perf_counter() - start
        print(f"{operation} took {duration:.2f} seconds")

with measure_time("model call"):
    result = model.generate("Summarize this text")
```

This makes sure the timing is recorded whether the model call succeeds or fails.

## How the topics fit together

A simple AI document pipeline may use all four concepts:

```text
Function:
Clean the document

OOP:
DocumentLoader stores loading behavior

Generator:
Read and process documents one at a time

Context manager:
Safely open files or database connections
```

Example:

```python
class DocumentLoader:
    def __init__(self, path):
        self.path = path

    def read_lines(self):
        with open(self.path, "r") as file:
            for line in file:
                yield line.strip()
```

This example uses:

- A class: `DocumentLoader`.
- A method: `read_lines()`.
- A context manager: `with open(...)`.
- A generator: `yield`.
- Lazy processing: lines are read one at a time.

## Easy memory guide

Remember the four topics like this:

- **Functions:** Small reusable jobs.
- **OOP:** Group related data and behavior.
- **Generators:** Produce one item at a time.
- **Context managers:** Safely start and clean up resources.

The main practical rule is:

> Use functions for small tasks, classes for organized components, generators for large or streamed data, and context managers for resources that must be cleaned up safely.
