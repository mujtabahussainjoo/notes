# Python Data Structures – Short & Simple

## `list`

A list is an ordered, changeable collection.

```python
skills = ["Python", "Magento", "React"]
skills.append("RAG")        # add at end
skills[0] = "Django"        # change item
print(skills[1])            # "Magento"
```

Use a list when:
- Order matters.
- You need to add/remove items.
- You may have duplicates.

---

## `tuple`

A tuple is an ordered, **immutable** (cannot change) collection.

```python
point = (10, 20)
x, y = point                # unpacking
print(x)                    # 10
# point[0] = 5              # ERROR: cannot change
```

Use a tuple when:
- You want a fixed group of values (e.g., coordinates, config).
- You don’t want accidental changes.
- You need a simple, lightweight record.

---

## `dict`

A dict is a collection of **key → value** pairs. Keys must be unique.

```python
user = {
    "name": "Mujtaba",
    "role": "Developer",
    "age": 30
}

print(user["name"])         # "Mujtaba"
user["city"] = "Kolkata"    # add new key
user["age"] = 31            # update value
```

Use a dict when:
- You need to look up values by a key (name, ID, code).
- Data is naturally “labeled” (fields of a record).
- You need fast lookups by key.

---

## `set`

A set is an unordered collection of **unique** items.

```python
tags = {"ai", "python", "ai"}  # duplicate "ai" is removed
print(tags)                    # {"ai", "python"}

tags.add("rag")
"python" in tags               # True (fast membership test)
```

Use a set when:
- You only care about uniqueness (no duplicates).
- You need fast “is this in the collection?” checks.
- You want to do math-like operations (union, intersection).

---

## List comprehensions

A compact way to create lists using a loop and optional condition.

Basic form:

```python
nums = [1, 2, 3, 4]
squares = [n * n for n in nums]
# [1, 4, 9, 16]
```

With condition:

```python
evens = [n for n in nums if n % 2 == 0]
# [2, 4]
```

More complex expression:

```python
labels = [f"num_{n}" for n in nums]
# ["num_1", "num_2", "num_3", "num_4"]
```

Use list comprehensions when:
- You’re building a new list from an existing iterable.
- The logic is simple (one loop, maybe one condition).
- You want clear, concise code.

---

## Dict comprehensions

A compact way to create dictionaries.

Basic form:

```python
nums = [1, 2, 3]
squares_map = {n: n * n for n in nums}
# {1: 1, 2: 4, 3: 9}
```

With condition:

```python
even_squares = {n: n * n for n in nums if n % 2 == 0}
# {2: 4}
```

Transform keys/values:

```python
names = ["a", "b", "c"]
indexed = {i: name for i, name in enumerate(names)}
# {0: "a", 1: "b", 2: "c"}
```

Use dict comprehensions when:
- You’re building a new dict from an iterable.
- The mapping rule is simple and clear.

## When to use which structure

### For performance

- Need fast lookup by key (e.g., user by ID)? → **dict**
- Need fast “is this present?” checks? → **set**
- Need ordered, indexable collection you can modify? → **list**
- Need a small, fixed group of values? → **tuple**

Typical big-O (average case):

- `list` index by position: `O(1)`
- `dict` lookup by key: `O(1)`
- `set` membership test: `O(1)`
- `list` membership test (`x in list`): `O(n)` (slower for large lists)

### For clarity

- Sequence of items where order matters → **list**
  ```python
  logs = ["start", "process", "end"]
  ```
- Fixed record with named fields → **dict**
  ```python
  user = {"id": 1, "name": "Mujtaba"}
  ```
- Small fixed-size group (e.g., coordinates) → **tuple**
  ```python
  size = (1920, 1080)
  ```
- Collection of unique tags/IDs → **set**
  ```python
  allowed_ips = {"10.0.0.1", "10.0.0.2"}
  ```

### Simple rules of thumb

- “I need to look up by ID/name” → **dict**
- “I just need to know if something exists” → **set**
- “I need an ordered, changeable list” → **list**
- “This should never change” → **tuple**
- “I’m transforming a list/dict in a simple way” → use **comprehensions**.
