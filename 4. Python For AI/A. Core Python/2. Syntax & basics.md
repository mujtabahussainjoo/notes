# Python Syntax & Basics

Python is designed to be readable. It uses indentation (spaces at the start of a line) to define code blocks instead of `{}` braces.

```python
# This is a comment
print("Hello, world!")

if True:
    print("This line is indented")
```

- Python is case-sensitive: `name` and `Name` are different variables.
- A statement usually ends at the end of its line; semicolons are normally unnecessary.
- Use 4 spaces for each indentation level.

# Variables, Data Types & Operators

A variable is a name that refers to a value. Python infers the type automatically.

```python
name = "Mujtaba"       # str: text
age = 30                # int: whole number
price = 99.50           # float: decimal number
is_active = True        # bool: True or False
nothing = None          # NoneType: no value
```

Common collection types:

```python
skills = ["Python", "Magento"]              # list: ordered, changeable
profile = {"name": "Mujtaba", "age": 30}  # dict: key-value data
tags = {"ai", "python"}                     # set: unique values
dimensions = (1920, 1080)                    # tuple: ordered, usually fixed
```

Useful operators:

```python
# Arithmetic
result = 10 + 5     # 15
result = 10 * 5     # 50
result = 10 / 4     # 2.5
result = 10 // 4    # 2, integer division
result = 10 % 4     # 2, remainder
result = 2 ** 3     # 8, power

# Comparison: result is True or False
10 > 5              # True
10 == 10            # True
10 != 5             # True

# Logical
True and False      # False
True or False       # True
not True            # False
```

# Control Flow

Control flow decides which code runs and how often it runs.

## `if`, `elif`, `else`

Use these statements to run code only when a condition matches.

```python
score = 75

if score >= 90:
    grade = "A"
elif score >= 60:
    grade = "B"
else:
    grade = "C"

print(grade)  # B
```

## `for`

Use a `for` loop to process every item in an iterable such as a list, string, or range.

```python
for skill in ["Python", "RAG", "React"]:
    print(skill)

for number in range(1, 4):
    print(number)  # 1, then 2, then 3
```

## `while`

Use a `while` loop while a condition remains true. Ensure the condition eventually becomes false.

```python
attempts = 0

while attempts < 3:
    print("Trying...")
    attempts += 1
```

Loop controls:

```python
for number in range(5):
    if number == 2:
        continue  # Skip this iteration
    if number == 4:
        break     # Stop the loop
    print(number) # 0, 1, 3
```

# Functions, Default Args, `*args`, `**kwargs`

A function groups reusable logic. Define it with `def` and return a result with `return`.

```python
def add(a, b):
    return a + b

print(add(2, 3))  # 5
```

## Default arguments

A default value is used when the caller does not provide that argument.

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Mujtaba"))           # Hello, Mujtaba!
print(greet("Mujtaba", "Hi"))     # Hi, Mujtaba!
```

## `*args`

`*args` collects extra positional arguments into a tuple.

```python
def total(*numbers):
    return sum(numbers)

print(total(10, 20, 30))  # 60
```

## `**kwargs`

`**kwargs` collects extra named arguments into a dictionary.

```python
def show_profile(**details):
    print(details["name"])
    print(details["role"])

show_profile(name="Mujtaba", role="Developer")
```

A function can use both when needed:

```python
def log_event(event, *messages, **metadata):
    print(event, messages, metadata)

log_event("user_login", "Successful login", user_id=42)
```

# Modules, Packages, Imports & Virtual Environments

## Modules

A module is a single Python file containing reusable code. Python includes many built-in modules.

```python
import math

print(math.sqrt(16))  # 4.0
```

You can import a specific item or give a module an alias.

```python
from datetime import date
import pandas as pd

print(date.today())
```

Example custom module:

```text
project/
├── helpers.py
└── app.py
```

```python
# helpers.py
def format_name(name):
    return name.title()

# app.py
from helpers import format_name
print(format_name("mujtaba"))  # Mujtaba
```

## Packages

A package is a directory that groups related Python modules. Modern Python commonly supports package directories with or without an `__init__.py` file, though including it is still common for explicit packages.

```text
my_app/
├── app.py
└── services/
    ├── __init__.py
    └── llm_client.py
```

```python
from services.llm_client import create_client
```

## Virtual environments

A virtual environment isolates dependencies for one project. It prevents one project's package versions from affecting another project's packages.

Create and activate one:

```bash
# Create it
python -m venv .venv

# Activate on macOS/Linux
source .venv/bin/activate

# Activate on Windows PowerShell
.venv\Scripts\Activate.ps1

# Install a package in the active environment
python -m pip install requests
```

Save dependencies for reproducible setup:

```bash
python -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
```
