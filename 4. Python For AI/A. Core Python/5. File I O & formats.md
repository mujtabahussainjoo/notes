## File I/O & formats

### Reading and writing text files

Basic read:

```python
with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)
```

Basic write (overwrites file):

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Line 1\n")
    f.write("Line 2\n")
```

Append (add to end):

```python
with open("notes.txt", "a", encoding="utf-8") as f:
    f.write("New line\n")
```

Read line by line (good for large files):

```python
with open("notes.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

`with` automatically closes the file, even if an error occurs.

### Working with paths (`pathlib`)

Modern way to handle paths:

```python
from pathlib import Path

base = Path("data")
file_path = base / "notes.txt"  # data/notes.txt

file_path.write_text("Hello", encoding="utf-8")
content = file_path.read_text(encoding="utf-8")
```

Check if file exists:

```python
if file_path.exists():
    print("File exists")
```

List files in a directory:

```python
for p in Path("data").iterdir():
    print(p)
```

### JSON (structured text data)

JSON is good for config, API data, simple records.

Write JSON:

```python
import json

data = {
    "name": "Mujtaba",
    "role": "Developer",
    "skills": ["Python", "Magento"]
}

with open("user.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2)
```

Read JSON:

```python
import json

with open("user.json", "r", encoding="utf-8") as f:
    data = json.load(f)

print(data["name"])      # "Mujtaba"
print(data["skills"][0]) # "Python"
```

### CSV (tabular data)

Good for simple tables, exports, imports.

Write CSV:

```python
import csv

rows = [
    ["name", "role"],
    ["Mujtaba", "Developer"],
    ["Amit", "Tester"],
]

with open("users.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(rows)
```

Read CSV:

```python
import csv

with open("users.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

Read as dicts (using header):

```python
import csv

with open("users.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], row["role"])
```

### Binary files (images, etc.)

Use binary mode (`"rb"`, `"wb"`) for non-text files.

Copy an image:

```python
with open("input.png", "rb") as src:
    data = src.read()

with open("output.png", "wb") as dst:
    dst.write(data)
```

***

### Choosing a format

- **Plain text (.txt)**  
  - Simple logs, notes.  
  - Use when structure doesn’t matter.

- **JSON (.json)**  
  - Config files, API responses, nested data.  
  - Easy to read/write from Python and JS.  
  - Use when you need structured, hierarchical data.

- **CSV (.csv)**  
  - Tables, reports, data exports.  
  - Use when data is row/column based and you might open it in Excel/Sheets.

- **Binary (images, audio, custom formats)**  
  - Use when data is not text (images, models, serialized objects).

### Simple patterns for real code

**Load config from JSON:**

```python
import json
from pathlib import Path

config_path = Path("config.json")

if config_path.exists():
    config = json.loads(config_path.read_text(encoding="utf-8"))
else:
    config = {"debug": False}
```

**Save simple log to text:**

```python
from datetime import datetime
from pathlib import Path

log_path = Path("app.log")
message = f"{datetime.now()} - Event occurred\n"

with log_path.open("a", encoding="utf-8") as f:
    f.write(message)
```

**Export data as CSV:**

```python
import csv
from pathlib import Path

users = [
    {"name": "Mujtaba", "role": "Developer"},
    {"name": "Amit", "role": "Tester"},
]

path = Path("users.csv")

with path.open("w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "role"])
    writer.writeheader()
    writer.writerows(users)
```

Use `pathlib` for paths, `open` with `with` for safety, and pick JSON/CSV/text based on how structured your data is.
